# One-Line Office Joke: 24-Hour Sprint

Entry for make.fun competition
`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162` by @cakraegg.

## The joke

> I asked for a raise and got a pizza party, so now I'm the only employee paid in pepperoni and broken promises.

110 characters, one line.

## How it works

`main.py` is Python 3 standard library only. It holds the joke as a
fixed string, validates it (1–200 characters, single line, not only
whitespace), and writes it to `/output/entry.txt`. No randomness, no
network, no clock — every run produces byte-identical output.

Run it with:

```sh
python3 main.py
```
